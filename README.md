# Digital-IT-Hub-in-Wurzburg

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Routes

| Route       | Description   |
| ----------- | ------------- |
| `/`         | Homepage      |
| `/news`     | News page     |
| `/events`   | Events page   |
| `/projects` | Projects page |
